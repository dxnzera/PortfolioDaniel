# Daniel Mendes

Portfólio de desenvolvimento front-end e design, com projetos web e mobile e avatar 3D. Feito com Next.js, React, TypeScript, Three.js e GSAP.

## Como usar

Requer Node.js 20.9 ou superior.

```bash
npm ci
npm run dev
```

Abra [localhost:3000](http://localhost:3000).

Para produção: `npm run build` e `npm start`. Defina `NEXT_PUBLIC_SITE_URL` com o domínio publicado; veja `.env.example`.
